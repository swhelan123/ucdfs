Dashboard blocks
Blocks are the headings the dashboard is divided into. The first one is where a card with no block of its own lands, and it is drawn at the top under the filter chips. A block with nothing in it is not shown on the dashboard at all, so an empty one is not a mistake, it is just waiting.

A block can only be deleted once it is empty. Cards do not move when a block goes, they just stop being where you filed them, and some of them are built into the site and cannot be re-filed from here.
Dashboard links
Links are the dashboard's off-site shortcuts: Onshape, SharePoint, the VCU repo. Adding one here puts it on everyone's dashboard straight away, with no deploy. Pages built into this site are not links and are not editable here, because each one is a file that has to ship with the code.

Subteams decide which filter chip a card shows under, and nothing else. They are not permissions: anybody can open any link on this list. Quiet dims a card without removing it, for something off-season or superseded.
member is the default. committee gets the Competition Hub admin actions: roster, shop runs, marking things bought. admin can open this page and switch on admin override.

Delete removes an account for good (sign-in, profile, photo and prompts) for the wrong-email signup that can't be merged. It appears with admin override on, never for yourself, and never for another admin: demote them first. Attendance and activity history stay behind, under the name that was typed; tidy those on the attendance page and the dashboard feed.
